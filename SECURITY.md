# Security policy

Documents Made Clear is not currently approved for public production use.
The vector-store production allowlist remains empty; no environment variable
may waive that gate. See [release blockers](docs/SECURITY_RELEASE_GATE.md).

Do not post real PDFs, credentials, tokens, private logs or exploit payloads in
public issues. Use the repository's private vulnerability-reporting channel if
the maintainer has enabled it; otherwise contact the maintainer through an
already-established private channel. No reporting address is invented here.

Reports should identify the affected revision, trust boundary, impact and a
minimal synthetic reproduction. Acknowledge uncertainty and preserve evidence.
Dependency scans, pattern-based secret checks and model audits do not prove
absence of vulnerabilities or legal/factual correctness.
