# Security policy

NOMIKOS SYNERGATHS is a development project and is not approved for production
or confidential customer documents. PostgreSQL/pgvector has replaced the old
Chroma runtime, but production deployment, provider encryption, offsite recovery
and signed release controls remain unverified. See the [security release gate](docs/SECURITY_RELEASE_GATE.md).

Do not post real PDFs, credentials, tokens, private logs or exploit payloads in
public issues. Use the repository's private vulnerability-reporting channel if
the maintainer has enabled it; otherwise contact the maintainer through an
already-established private channel. No reporting address is invented here.

Reports should identify the affected revision, trust boundary, impact and a
minimal synthetic reproduction. Dependency scans, pattern-based secret checks
and model audits do not prove absence of vulnerabilities or factual correctness.
