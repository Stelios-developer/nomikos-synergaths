# Narrated product walkthrough

A 1 minute 55 second walkthrough of the actual frontend using the isolated
synthetic demo fixture. It shows the library, overview, facts and obligations,
timeline, risks, action plan, decision center, evidence and document assistant.
The edit uses screenshots of the interactive demo; it is not a continuous live
recording or proof of a running backend.

- [Video with English narration](nomikos-demo-en.mp4) — H.264/AAC, 1280×720.
- [Greek subtitles](captions-el.srt) · [English subtitles](captions-en.srt).
- [Narration and scene descriptions](storyboard.json).

English narration was generated locally using Microsoft Zira Desktop; no paid
voice service was used. English captions are embedded in the picture; subtitle
files are separately available. The sample account, case, citations and assistant
answer are synthetic. No actual PDF, authentication, provider call or real AI
answer is demonstrated. Product security and production readiness remain subject
to the [release gate](../SECURITY_RELEASE_GATE.md).

The [interactive demo](../DEMO.md) can be run locally without the backend.
