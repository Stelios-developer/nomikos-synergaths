# NOMIKOS SYNERGATHS — Ελληνικός οδηγός

Το NOMIKOS SYNERGATHS βοηθά στην εξερεύνηση εγγράφων PDF: οργανώνει γεγονότα,
υποχρεώσεις, προθεσμίες και κινδύνους και συνδέει τις απαντήσεις με τις σελίδες
της πηγής. Οι προτεινόμενες ενέργειες και τα συμπεράσματα χρειάζονται ανθρώπινο
έλεγχο, ειδικά για νομικές ή οικονομικές αποφάσεις.

Η εφαρμογή βρίσκεται σε ανάπτυξη και δεν έχει εγκριθεί για χρήση με πραγματικά
έγγραφα πελατών. Η ανάλυση μπορεί να στείλει σχετικά αποσπάσματα στον επιλεγμένο
πάροχο AI. Οι πραγματικές ρυθμίσεις ασφάλειας και αποθήκευσης πρέπει να ελεγχθούν
πριν από το production.

Για εγκατάσταση και δοκιμές: [Οδηγίες ανάπτυξης](DEVELOPMENT.md),
[έλεγχοι](TESTING.md) και [αρχιτεκτονική](ARCHITECTURE.md). Για τους ελέγχους
πριν από δημοσίευση: [Security release gate](SECURITY_RELEASE_GATE.md) και
[Release runbook](engineering/RELEASE_RUNBOOK.md).
